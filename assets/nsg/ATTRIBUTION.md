# NSG game symbols and faction glyphs

The SVG files in this folder are unmodified copies from the Null Signal Games Visual Assets pack v1.5
(https://access.nullsignal.games/), licensed under Creative Commons Attribution-NoDerivatives 4.0
International (CC BY-ND 4.0): https://creativecommons.org/licenses/by-nd/4.0/

`factions/*.png` are the pack's faction glyph SVGs converted to 512px PNG (format conversion only,
because two of the SVGs embed raster images that the app's SVG renderer can't draw).

Symbols are recoloured at runtime (ColorFilter) and faction glyphs are shown in greyscale, which
NSG's terms state is not a derivative work. This app is a fan-made tool and is not affiliated with or
endorsed by Null Signal Games.
